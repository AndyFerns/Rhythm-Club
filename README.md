# Rhythm Club FCRIT

Welcome to the official website repository of **Rhythm Club FCRIT** — the musical heartbeat of Fr. C. Rodrigues Institute of Technology.

Rhythm Club is home to everyone who loves music, whether you're a singer, guitarist, pianist, drummer, beatboxer, producer, or simply someone who enjoys being around great performances and even better people. From energetic jam sessions and cultural festivals to college events and competitions, the club celebrates creativity, collaboration, and the joy of making music together.

> This small project is a modern, interactive website built to showcase the club, its members, and its events while giving visitors a glimpse into the vibrant community behind Rhythm.

## Features (For those looking to contribute)

* Interactive landing page with animated curtain intro
* 3D background model powered by Three.js
* Music-reactive particle effects
* Dynamic team and event sections generated from local data
* Event modal with detailed information
* Smooth scrolling and GSAP-powered animations
* Responsive design built with Tailwind CSS
* Social media and contact links managed through a centralized data file

## Built With

* HTML5
* CSS3
* JavaScript (ES Modules)
* Tailwind CSS
* Three.js
* GSAP
* tsParticles
* Font Awesome

## About Rhythm

Music has a way of bringing people together, and that's exactly what Rhythm Club strives to do. Whether it's performing on stage, organizing college events, collaborating with fellow musicians, or simply sharing a love for music, the club is built around creating unforgettable experiences and lasting friendships.

If you're passionate about music, there's always a place for you in Rhythm.
